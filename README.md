# Mlops. Домашняя работа 2 

По условию надо отправить транзакции из файла в ClickHouse и выдать категорию самой крупной транзакции для каждого штата. Файл `train.csv` надо положить в `teta-ml-1-2025/` в корне директории

- `producer.py`, `requirements.txt`, `Dockerfile` - отправка csv в Kafka и зависимости
- `docker-compose.yml` - описывает контейнеры с Kafka, ClickHouse и контейнер producer
- `schema_v2.sql`, `query_v2.sql` - оптимизированная версия таблицы и запроса
- `run_v2.sh` - запуск скрипта


результат сохраняется в `result.csv`

Оптимизация с помощью Materialized View, максимумы по штатам для каждого батча сохраняются в отдельной таблице, итоговый запрос их объединяет

```bash
bash solution/run_v2.sh
```
